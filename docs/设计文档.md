# 设计文档 — 角色连衣裙布料模拟（Blender Cloth Gallery）

> 项目路径：`Portfolio/Gallery/Cloth`
> 软件版本：**Blender 4.5.0**（.blend 文件头标识 `BLENDER-v405`）
> 渲染引擎：**Cycles**
> 文档日期：2026-10-28

---

## 1. 项目概述

本项目是一个以 **布料（Cloth）物理模拟** 为核心的 Blender 作品展示项目，是作者跟随 YouTube 视频教程学习制作的成果。项目主体是一个 **VRM 格式的动漫风格角色**，通过 Blender 的 Cloth 修改器，为角色身上的 **连衣裙（Dress）** 添加真实的布料物理模拟，并最终用 Cycles 渲染出两张成品图。

项目的学习与展示目标集中在三点：

1. **VRM 角色的导入与使用** —— 掌握在 Blender 中导入、驱动 VRM 动漫角色（含完整人体骨骼、弹簧骨骼、MToon 卡通着色、表情 BlendShape）。
2. **布料模拟** —— 理解 Cloth 修改器的物理参数（质量、阻尼、碰撞、固定点等），让裙子随姿态自然垂坠、摆动。
3. **卡通角色 + 写实布料的视觉融合** —— 让二次元角色与具有真实纹理/法线的布料在 Cycles 下自然融合。

## 3. 场景构成设计

从 `.blend` 文件的二进制数据中解析出的场景结构如下（数据来源：对 `blend/Cloth2.blend` 解压后解析其 Block 结构）。

### 3.1 场景规模

| 元素 | 数量 |
|------|------|
| 对象（Object） | 22 个 |
| 网格（Mesh） | 15 个 |
| 集合（Collection） | 4 个（另含场景默认集合） |
| 灯光（Light） | 3 个 |
| 相机（Camera） | 1 个 |
| 场景（Scene） | 1 个 |
| 骨骼（Armature） | 1 套（VRM 完整人形骨骼 + 弹簧骨骼） |

### 3.2 集合（Collection）层级

解析到的集合命名体现了清晰的分组设计：

- **Scene Collection** —— 根集合
- **Character** —— 角色整体（身体、脸、头发、服装部件、骨骼等）
- **Cloth** —— 布料相关（连衣裙 Dress）
- **Shoe** —— 鞋子
- **Button** —— 纽扣/装饰件

> 这种「角色 / 布料 / 配件」的集合分组，说明作者有意识地把 **动态模拟对象（Cloth）** 与 **静态角色身体** 分开管理，便于单独调整布料模拟与缓存。

### 3.3 角色构成

角色由多个独立网格部件组成，部件命名（解析自对象 ID 名）如下：

| 部件对象名 | 含义 |
|-----------|------|
| `Body` | 身体 |
| `Face` | 面部 |
| `Hair` | 头发 |
| `Shorts` | 短裤 |
| `Dress` | 连衣裙（**布料模拟主体**） |
| `Bow` / `Bow2` / `Bow3` | 蝴蝶结装饰（3 个） |
| `Collar` / `Collar2` / `Collar3` | 领口/领结装饰（3 个） |
| `Flower` | 花饰（使用 `Flower.png` 纹理） |
| `Armature` | 角色骨骼 |

此外还有若干 `Circle`（圆形）与 `Area`（区域/地面）对象，推测用于布料碰撞约束、地面或场景背景。

### 3.4 灯光与相机

- **3 盏灯光** 提供基础的棚拍式布光，配合角色的 MToon 卡通着色（其自带 Rim 边缘光、Shading 明暗分界线等）。
- **1 台相机** 用于最终取景。

## 4. 视觉设计

### 4.1 角色（VRM 动漫角色）

- 采用 **VRM 格式** 动漫角色，通过 Blender 的 **VRM 插件**（VRM Add-on）导入。
- 角色使用 **MToon 卡通着色器**（VRM 1.0 标准的 MToon1），具有典型的二次元渲染特征：
  - **Lit Color / Shade Color**（受光色与阴影色，构成二分阴影）
  - **Shading Shift**（明暗分界线偏移）
  - **Rim Light**（边缘光）
  - **Outline Width**（描边宽度）
  - **MatCap / Emissive / Normal Map / UV Animation Mask** 等贴图通道
- 角色带有完整的 **表情 BlendShape**（`Fcl_*` 系列：喜怒哀乐、口型元音 A/I/U/E/O、眨眼、眉毛动作等），以及用于头发和胸部的 **弹簧骨骼（Spring Bone）** 物理，使角色更生动。

### 4.2 布料（连衣裙）

连衣裙是本作品的技术与视觉焦点：

- **材质风格**：写实布料质感，使用 PBR 工作流 —— `Principled BSDF` 着色器 + 基础色贴图 + 法线贴图。
- **纹理**：
  - `basecolor.png`（2048×2048，RGBA）—— 布料基础颜色/图案
  - `normal_map.png`（2048×2048，RGB）—— 布料法线细节，表现织物凹凸
- **色彩方向**：与角色整体色调协调，营造「二次元角色 + 真实织物」的融合观感。

### 4.3 装饰件

- **花饰（Flower）**：使用独立的 `Flower.png`（1920×1080，RGBA）纹理，作为服装上的点缀元素。
- **蝴蝶结（Bow×3）与领结（Collar×3）**：丰富服装层次与可爱感。

### 4.4 构图与输出

- 最终输出分辨率为 **1920×1080**（16:9 横构图）。
- 产出两张渲染图 `Cloth1.png` 与 `Cloth2.png`，推测分别对应不同姿态或不同布料模拟阶段/角度，用于展示裙摆的物理模拟效果。

## 6. 设计小结

本作品的设计核心是 **「让二次元动漫角色穿上会真实摆动、具有织物细节的连衣裙」**。它把两条通常独立的技术路线——VRM 卡通角色管线与 PBR 布料物理模拟——放在同一个场景里统一渲染，是一个典型的学习型作品：既练习了 VRM 角色的导入与材质，也掌握了 Cloth 布料模拟与 Cycles 渲染的完整流程。

> 说明：本文档中关于场景结构（对象、集合、灯光数量、命名）与材质（MToon、Principled BSDF）的内容，来自对 `blend/Cloth2.blend` 二进制文件的直接解析，属于可确认事实；而关于具体物理参数数值、灯光类型、帧范围、构图意图等细节为合理推断，可在 Blender 中进一步核对确认。
