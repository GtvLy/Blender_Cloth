## 3. .blend 文件解析结果

通过对 `Cloth2.blend` 进行 zstd 解压并解析其 Block 结构（`.blend` 格式的块头部：4 字节 code + 4 字节 size + 8 字节指针 + 4 字节 SDNA 索引 + 4 字节 count），得到如下数据块分布：

| Block Code | 含义 | 数量 | 说明 |
|-----------|------|------|------|
| `SC` | Scene | 1 | 场景数据（含渲染设置、分辨率 1920×1080） |
| `OB` | Object | 22 | 场景对象 |
| `ME` | Mesh | 15 | 网格数据 |
| `GR` | Collection | 4 | 集合 |
| `LA` | Light/Lamp | 3 | 灯光 |
| `CA` | Camera | 1 | 相机 |
| `CU` | Curve | 1 | 曲线 |
| `WM` | WindowManager | 1 | 窗口管理器 |
| `WS` | WorkSpace | 11 | 工作区布局 |
| `SN` | （场景节点/声音等） | 11 | — |
| `DATA` | 主数据块 | 1（内部含大量子结构） | 绝大多数实际数据 |
| `GLOB` | Global | 1 | 全局设置 |
| `REND` | 渲染结果信息 | 1 | 保存时的渲染状态 |

> 结论：场景规模为 **22 个对象 / 15 个网格 / 3 盏灯 / 1 台相机 / 1 套骨骼 / 4 个集合**。

## 4. 角色系统（VRM）

### 4.1 模型与导入

角色模型 `Character.vrm` 为 VRM 格式（基于 glTF 2.0 二进制），通过 Blender **VRM Add-on** 导入（二进制中可见 `VRM_PT_*` 系列插件面板、`vrm_addon_extension` 等标识）。

### 4.2 骨骼（Armature）

角色采用 Unity Mecanim 人形骨骼命名规范（`J_Bip_*` 前缀），解析到的主要骨骼：

- **躯干**：`J_Bip_C_Hips`、`J_Bip_C_Spine`、`J_Bip_C_Chest`、`J_Bip_C_UpperChest`、`J_Bip_C_Neck`、`J_Bip_C_Head`
- **手臂（左/右）**：`J_Bip_L/R_Shoulder` → `UpperArm` → `LowerArm` → `Hand`，以及 5 根手指 × 3 段（`Index`/`Middle`/`Ring`/`Little`/`Thumb`）
- **腿部（左/右）**：`J_Bip_L/R_UpperLeg` → `LowerLeg` → `Foot` → `ToeBase`

此外还包含 **VRM 弹簧骨骼（Spring Bone）**，用于二次元的动态物理：

- **头发**：`J_Sec_Hair1_01` … `J_Sec_Hair5_15`（大量分段，驱动发丝摆动）
- **胸部**：`J_Sec_L_Bust1/2`、`J_Sec_R_Bust1/2`
- **面部**：`J_Adj_L/R_FaceEye`（眼部调整）

### 4.3 表情 BlendShape

角色带完整的 VRM 表情 Shape Key（`Fcl_*` 系列）：

- 情绪类：`Fcl_ALL_Neutral / Angry / Fun / Joy / Sorrow / Surprised`
- 眉毛：`Fcl_BRW_*`、眼睛：`Fcl_EYE_*`（含眨眼、高光隐藏等）、嘴部：`Fcl_MTH_*`（含元音口型 A/I/U/E/O）、头发：`Fcl_HA_*`

### 4.4 材质（MToon1）

角色使用 VRM 1.0 标准的 **MToon1 卡通着色器**，节点系统包含多个贴图通道（解析到的节点标识）：

- `Mtoon1BaseColorTexture`（基础色 / Lit Color）
- `Mtoon1ShadeMultiplyTexture`（阴影色）
- `Mtoon1ShadingShiftTexture`（明暗分界线偏移）
- `Mtoon1EmissiveTexture`（自发光）
- `Mtoon1RimMultiplyTexture`（边缘光）
- `Mtoon1OutlineWidthMultiplyTexture`（描边宽度）
- `Mtoon1MatcapTexture`（MatCap 材质捕获）
- `Mtoon1NormalTexture`（法线贴图）
- `Mtoon1UvAnimationMaskTexture`（UV 动画遮罩）

另有 MToon 描边材质：`MToon Outline (N00_000_00_Face_00_SKIN (Instance))`。

角色的内置贴图（`//textures/_01.png` … `_14.png`、`MatcapWarp.png`、`N00_000_00_Face_00_out.png` 面部描边、`N00_000_Hair_00_nml.png` 头发法线等）以相对路径引用，随 VRM 文件一起打包在模型内部/同级 `textures` 目录中。

## 5. 布料模拟（Cloth）

### 5.1 模拟对象

布料的模拟主体是 **`Dress`（连衣裙）** 对象，位于 `Cloth` 集合中。从二进制数据中解析到 `Cloth` 修改器及其数据结构：

- `ClothModifierData` —— Cloth 修改器数据
- `ClothSimSettings` —— 布料模拟参数
- `ClothCollSettings` —— 布料碰撞参数

解析到的 Cloth 相关参数字段（`cloth_*`）：

| 参数字段 | 含义 |
|---------|------|
| `cloth_mass` | 布料质量 |
| `cloth_damping` | 阻尼（抑制弹性抖动） |
| `cloth_sim_limit` | 模拟步数限制 |
| `cloth_sim_falloff` | 模拟衰减 |
| `cloth_deform_type` | 形变类型 |
| `cloth_force_falloff_type` | 力衰减类型 |
| `cloth_simulation_area_type` | 模拟区域类型 |
| `cloth_constraint_softbody_strength` | 约束/软体强度 |
| `seam_margin` / `sewing` | 缝合相关 |

同时存在完整的物理缓存体系（`*pointcache`、`ptcaches`、`cache_frame_start/end`、`cache_frame_pause_*`、`cache_directory`、`cache_type`、`cache_comp` 等），说明布料模拟结果被 **烘焙缓存（Bake Cache）**，以保证渲染时布料状态稳定。

### 5.2 碰撞与固定

- 角色身体（`Body`）、短裤（`Shorts`）等作为布料的 **碰撞体（Collision）**，使裙子不穿透身体。
- 场景中的多个 `Circle` 圆形对象与 `Area` 对象，推测用于布料约束/固定点（Pin）或碰撞。
- 布料在腰部/肩带处应有 **固定顶点组（Pin Group）**，使裙子挂在角色身上而非整体掉落（此为 Cloth 模拟的标准做法，具体顶点组名称可在 Blender 中确认）。

## 6. 材质与着色器（布料部分）

连衣裙使用 **PBR 工作流**，材质节点树包含（解析到的节点标识）：

- `Principled BSDF`（`ShaderNodeBsdfPrincipled`）—— 核心 PBR 着色
- `Image Texture` —— 基础色贴图 `basecolor.png`
- `Image Texture.001` —— 法线贴图 `normal_map.png`
- `Texture Coordinate` —— UV 坐标
- `Mapping` / `ShaderNodeMapping` —— UV 变换
- `Material Output` —— 材质输出
- `Normal Map` 节点 —— 将法线贴图接入 Principled BSDF

花饰（`Flower`）使用独立贴图 `Flower.png`。

## 8. 渲染设置（Cycles）

- **渲染引擎**：Cycles（二进制中含 `CYCLES_RENDER_PT_sampling`、`CYCLES_RENDER_PT_sampling_render_denoise`、`CYCLES_RENDER_PT_bake` 等面板，以及 `compute_device_type`、`gpu_preferred_index` 等设备配置字段）。
- **输出分辨率**：**1920×1080**（场景数据中解析到 `1920` 与 `1080` 两个 int32 值，与 `Output/*.png` 实际尺寸一致）。
- **降噪**：启用降噪（`use_denoising`、渲染采样降噪面板存在）。
- **成品**：`Output/Cloth1.png` 与 `Output/Cloth2.png`。

> 提示：具体采样数（Samples）、光追反弹次数、降噪器类型（OptiX/OpenImageDenoise）、帧范围（frame_start/frame_end）等精确数值需在 Blender 的渲染面板中查看，本文档不逐一定值。

## 9. 工作流程（制作管线）

基于项目文件可推断的完整制作流程：

1. **导入 VRM 角色**：用 VRM Add-on 导入 `Character.vrm`，得到含骨骼、MToon 材质、表情、弹簧骨骼的完整角色。
2. **整理场景**：将角色部件按 `Character / Cloth / Shoe / Button` 等集合分组。
3. **配置布料**：为 `Dress` 添加 Cloth 修改器，设置质量、阻尼、碰撞、固定点等参数，并配置身体为碰撞体。
4. **烘焙布料缓存**：运行并烘焙布料模拟（生成 point cache），保证渲染稳定。
5. **制作布料材质**：为连衣裙创建 Principled BSDF 材质，接入 `basecolor.png` + `normal_map.png`。
6. **布置灯光与相机**：放置 3 盏灯 + 1 台相机，完成取景与棚拍布光。
7. **Cycles 渲染输出**：以 1920×1080 输出成品图 `Cloth1.png` / `Cloth2.png`。
8. **归档**：打包为 `Blender_Cloth.zip` 保存。

## 10. 关键技术要点总结

1. **VRM 角色管线**：完整人形骨骼（Mecanim 命名）+ 弹簧骨骼（头发/胸部）+ MToon1 卡通着色 + VRM 表情 BlendShape。
2. **布料物理**：Cloth 修改器 + 碰撞体 + Pin 固定 + 烘焙缓存，实现裙摆自然垂坠与摆动。
3. **材质双轨**：角色走 MToon 卡通（非写实），布料走 Principled BSDF（写实 PBR），通过 Cycles 统一渲染，实现风格融合。
4. **工程规范**：清晰的集合分组、`.blend` 采用 zstd 压缩、附带自动备份（`.blend1`）与打包归档（`.zip`）。
